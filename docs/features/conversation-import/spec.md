# 大模型对话导入

## 功能边界

接收标准化对话 JSON，保留会话、消息、角色、时间、顺序、分支和附件引用。

## 验收标准

### 有效对话

- Given 用户提交符合协议的对话 JSON
- When 调用对话导入接口
- Then 系统创建 ConversationSource、会话和消息记录，并返回导入任务 ID

### 对话结构保留

- Given 对话包含多条消息、不同角色或分支
- When 系统完成标准化
- Then 消息顺序、角色、时间、会话 ID 和父消息关系保持不变

### 非法数据

- Given JSON 缺少会话 ID、消息角色或消息内容
- When 调用导入接口
- Then 系统拒绝该请求并返回字段级错误

### 幂等导入

- Given 同一会话和消息 ID 已经导入
- When 再次提交相同消息
- Then 系统不产生重复消息，并返回已有导入结果

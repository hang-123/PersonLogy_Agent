# 访问控制

## 功能边界

控制项目、来源、原始文件、知识、AI 工具和 Schema 管理操作的访问权限，并记录审计事件。

## 验收标准

### 项目隔离

- Given 用户没有目标项目的访问权限
- When 用户请求知识、来源或检索结果
- Then 系统拒绝访问并不泄露项目存在性之外的信息

### 原文与知识分离

- Given 用户拥有知识读取权限但没有原始文件读取权限
- When AI 或用户请求知识详情
- Then 系统可以返回允许范围内的知识，但不返回受限原文内容

### AI 工具权限

- Given LLM 发起搜索、关系扩展或写入工具调用
- When 工具执行请求
- Then 系统根据当前用户、项目和工具权限进行校验

### Schema 管理权限

- Given 用户不是 Schema 管理员
- When 用户请求执行 Migration
- Then 系统拒绝执行，即使该用户可以提交变更建议

### 审计记录

- Given 用户或 AI 执行读取、写入、审核、Migration 或原文访问
- When 操作完成或失败
- Then 系统记录操作者、时间、项目、对象、结果和失败原因

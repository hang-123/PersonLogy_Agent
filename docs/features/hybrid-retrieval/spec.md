# 混合检索

## 功能边界

组合全文、向量和关系检索，为 AI 和用户组装带权限、关系路径和原文证据的结果。

## 验收标准

### 混合召回

- Given 用户提交自然语言问题
- When 检索服务执行查询
- Then 系统可以组合全文、向量和关系检索结果，并进行融合或重排

### 关系扩展

- Given 召回一个知识节点或 Claim
- When 查询要求解释其上下文
- Then 系统可以展开配置范围内的一至两跳关系，并返回关系类型和方向

### 证据组装

- Given 检索结果包含 Claim 或 Relation
- When 系统组装 AI 上下文
- Then 每条重要结论都带有原文片段、来源和定位信息

### 无证据回答

- Given 检索结果没有足够来源证据
- When AI 请求生成回答
- Then 系统标记不确定性或返回无法确认，不得伪造引用

### 权限过滤

- Given 用户只能访问部分项目或来源
- When 执行任意检索
- Then 召回结果、关系扩展和证据片段都不能越过授权范围

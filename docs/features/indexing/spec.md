# 索引构建

## 功能边界

为 Gel 主数据构建全文、向量和关系索引。索引是可重建的派生数据。

## 验收标准

### 增量索引

- Given 知识对象或关系成功写入 Gel
- When 索引任务被调度
- Then 系统只处理新增或变更对象，并更新对应全文、向量和关系索引

### 重建索引

- Given 索引损坏、模型更换或需要重新计算
- When 管理员启动索引重建
- Then 系统可以从 Gel 主数据重新生成索引，不依赖旧索引内容

### 索引失败

- Given Embedding 服务或索引任务失败
- When Worker 执行索引构建
- Then 主数据保持不变，任务记录失败原因并支持重试

### 版本记录

- Given 向量索引由某个 Embedding 模型生成
- When 系统保存索引状态
- Then 记录模型名称、维度、版本和生成时间

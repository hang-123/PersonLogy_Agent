# 前端交互

## 功能边界

提供资料上传、任务进度、知识浏览、关系图、人工审核、引用定位和问答交互。

## 验收标准

### 上传反馈

- Given 用户选择 PDF 或对话文件
- When 上传请求提交
- Then 页面显示上传结果、任务 ID 和处理状态

### 任务进度

- Given 导入任务正在执行
- When 用户查看任务详情
- Then 页面显示当前阶段、进度、失败原因和重试状态

### 知识浏览

- Given 项目中存在已发布知识
- When 用户浏览知识目录或关系图
- Then 页面显示知识类型、关系、验证状态和可点击来源

### 引用定位

- Given 知识点包含 PDF 或对话 Citation
- When 用户点击引用
- Then 页面打开对应 PDF 页码或对话消息位置

### 人工审核

- Given 用户拥有审核权限
- When 用户确认、驳回或修改候选知识
- Then 页面提交审核结果并显示新的知识状态

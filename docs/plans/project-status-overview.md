| 受控回写 | 审核版本验证、Schema 快照校验、幂等回写、OKF 副作用任务、索引任务 | SQLite 全链路已通过真实 API/Worker 测试；初始 Schema 快照需预先登记 |
| 检索与问答 | SQLite FTS/BM25、证据、关系扩展、检索式回答；可选 reranker | 向量检索未接通；Gel 检索/索引明确报不支持 |
| Web 工作台 | PDF/对话导入、任务、审核、检索、问答；接入当前 `/v1` 契约 | 任务与审核按选中项目请求；统一的导入流水线视图待做 |
| Schema 管理 | 快照、提案、校验、审批、执行、回滚接口及测试 | SQLite Registry 为当前运行时实现；真实 Gel DDL 仍用迁移工具 |
| 审计与可观测性 | 审计哈希链、血缘、监控、重放、备份一致性与导出能力 | SQLite 配置最完整；Gel 审计有独立适配器 |
| 任务可靠性 | 重试进度归零、每次执行期限、启动及 Worker 轮询恢复超时任务 | 不提供进程级强杀同步第三方调用或外部副作用的 exactly-once 保证 |
| 部署与 CI | API/Worker Docker 镜像、共享环境文件、本地包安装、真实进程 smoke、容器 smoke | Gel 证书校验默认开启；本机测试需显式允许自签名证书 |

## 本轮验收

- 后端 **91 passed，0 skipped**，包含连接真实 Gel 的 10 个测试；mypy 覆盖 141 个源文件。
- Ruff、前端 typecheck 和 production build 通过。
- 使用 `.env` 中 DeepSeek 配置完成：PDF → 解析 → LLM 编译 → 审核 → 回写 → 索引 → 带证据检索。
- 模拟崩溃任务恢复成功，重试次数为 2；启发式模式也通过相同流程。
- 生产依赖安装的 API / Worker 容器可启动并共享 SQLite 队列处理任务。
- Gel 隔离测试实例应用 00001–00004 迁移与 7 个 RelationType seed；默认 TLS 拒绝未信任自签名证书。

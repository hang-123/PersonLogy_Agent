# TP-12 API 与前端交互

## 目标

提供用户可操作的上传、进度、审核、知识浏览、关系图和问答界面。

## 负责范围

- API DTO 和版本；
- 上传和任务状态页面；
- 知识详情、关系图和引用定位；
- 审核页面；
- 带来源问答页面。

## 不负责

- 在路由中直接操作 Gel；
- 在前端执行 LLM Prompt；
- 绕过领域工具进行写入。

## 验收

- Given 用户上传合法 PDF
- When 页面提交上传
- Then 页面展示任务 ID、状态和失败原因

- Given AI 返回带 Citation 的回答
- When 用户点击引用
- Then 页面定位到 PDF 页码或对话消息

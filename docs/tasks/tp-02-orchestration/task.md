# TP-02 任务编排

## 目标

统一管理导入、解析、编译、治理和索引任务。

## 负责范围

- Job 状态机；
- Queue 和 Worker；
- 重试、幂等、超时和失败恢复；
- 任务进度查询。

## 不负责

- 具体解析和编译逻辑；
- 业务对象最终写入规则。

## 验收

- Given 一个合法导入请求
- When 创建任务
- Then 系统返回唯一任务 ID 并记录 queued 状态

- Given Worker 中途失败
- When 任务达到可重试条件
- Then 系统按策略重试并保留失败原因

- Given 相同幂等键重复提交
- When 创建任务
- Then 系统不产生重复任务

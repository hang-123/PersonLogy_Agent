# TP-10 混合检索

## 目标

组合全文、向量和关系查询，为 AI 组装可验证证据包。

## 负责范围

- 查询解析；
- 权限过滤；
- 全文/向量/关系结果融合；
- 一至两跳关系扩展；
- 结果重排；
- Citation 和原文片段组装。

## 不负责

- 原始资料写入；
- Schema Migration；
- 任意权限绕过。

## 验收

- Given 用户提出自然语言问题
- When 执行检索
- Then 结果可以同时包含知识、关系路径和原文证据

- Given 没有足够证据
- When 请求生成回答
- Then 系统返回不确定性，不伪造引用

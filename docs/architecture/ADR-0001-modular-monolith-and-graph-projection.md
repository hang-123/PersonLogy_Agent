# ADR-0001：模块化单体与可重建图投影

- 状态：Accepted
- 日期：2026-07-28

## 背景

P0 服务单用户，复杂度来自 Ontology、证据链、版本和推导约束，而不是高并发。同时项目需要用真实业务查询验证 Neo4j 的收益与成本。

## 决策

采用“模块化单体 + PostgreSQL 唯一权威源 + Neo4j 可重建异步投影”。发布事务只写 PostgreSQL 正式知识、审计和投影事件；Worker 在事务提交后幂等投影。图投影失败不回滚正式知识，查询可降级到 PostgreSQL。

## 结果

- 优点：事务边界清晰、领域模型易重构、图组件可退出、实验可对照。
- 代价：需要维护投影事件、版本、校验、重建和降级路径。
- 禁止：同步双写、绕过 PostgreSQL 写 Neo4j、在图中保存不可重建的唯一业务数据。
